# oxc_rabblings

OpenXcom Extended (OXCE) mod set in the Rabblings universe. Work in progress.

## Credits
RabblingsGeoscape v0.0.6 uses the Geoscape palette and land texture sheet from OXC_Factions by Luke83 (https://github.com/lxcom83/OXC_Factions). The texture sheet is indexed to that palette and must ship with it.

Interface colours (interfaces.rul) borrowed from OXC_Factions to match its palette.
